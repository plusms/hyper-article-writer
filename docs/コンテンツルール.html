PLUS記事 コンテンツルール & 公開前チェックリスト

記事作成・納品前に必ず確認してください。疑問があれば担当者に確認してから進めてください。

1記事の目的と基本構成

PLUSの記事は、検索してきたユーザーの悩みを解決し、次に取るべき行動を判断できる状態にすることが目的です。

記事全体を通じて 「悩み → 解決 → 行動」 の流れを意識して書いてください。

記事の基本構成

パーツ役割
記事タイトルメインKWを前半に置き、記事の内容が一目でわかる表現にする
記事冒頭の導入文ベネフィット（読後に得られる状態）を提示し、読み進める理由をつくる
H2 + 導入文 + H3×3〜4ユーザーが知りたい順に並べる。H2直下に1〜2文の導入を入れる
まとめ（H2として設置）「まとめ」という見出し名は使わない。記事全体の結論と次の行動を示す
メタディスクリプション80〜100文字。KWを含み、クリックしたくなる内容にする
KW構成の基本メインKW 1つ、サブKW 2つを設定します。メインKW・サブKWの検索意図に対応するH2を必ず設置してください。

2KWと記事タイプ

記事作成前に、担当者から指定される「記事タイプ」と「KW」の意味を理解してください。

記事タイプ

タイプ概要KWの例
ノウハウ施術・症状・成分などの情報を解説する。クリニック紹介なし。ツールの一括作成で生成「AGAとは」「育毛剤 効果」
一般（比較）複数クリニックをランキング形式で比較紹介。送客が主目的「AGA クリニック おすすめ」「クマ取り 比較」
地域地域絞り込みKW。その地域のクリニックを紹介する「AGA 大阪」「医療脱毛 渋谷」
商標特定クリニック・ブランドを探しているユーザーへの記事「TCB 料金」「湘南美容クリニック AGA」

メインKW・サブKW

種類役割設置場所
メインKW この記事で上位表示させたい主軸のKW。担当者から1つ指定される タイトル前半・冒頭文前半・H2前半に必ず含める
サブKW メインKWと検索意図が近いKW。担当者からカンマ区切りで指定される 各サブKWに対応するH2を最低1つ設置する
KWを詰め込まないメインKW・サブKWは規定の箇所に自然に含めます。不自然にKWを繰り返すとSEO評価が下がります。

カニバリゼーション（共食い）に注意

カニバリゼーションとは、同じサイト内で似たKWを狙う記事が複数存在することで、Googleがどちらを上位表示すべきか判断できなくなる現象です。結果として両方の記事の順位が下がります。

確認方法内容
Google検索site:サイトドメイン メインKW で検索し、同テーマの記事が既に存在しないか確認する
サーチコンソール既存記事のクエリ一覧を確認し、追加しようとするKWを既存記事が拾っていないか確認する
新規記事を追加する前に必ず確認同テーマ・類似KWの記事が既にある場合は、新規追加ではなく既存記事のリライトを検討してください。

3ベネフィットとは

ベネフィットとは「この記事を読んだ後、どんな良い状態になれるか」を伝えることです。単なる情報の説明にとどまらず、読後の状態変化まで書きます。

冒頭の導入文と、各H2直下の導入文で必ず使います。

NG vs OK の例

NG二重整形の料金プランを詳しく解説します。
OK広告には載っていない麻酔代やアフターケアを含めた総額がわかります。予算オーバーを防いで賢くクリニックを選ぶ判断材料にしてください。
NGICLで失敗する原因についてまとめました。
OK手術の「リスク」だけでなく、失敗を避けるためのクリニック選びの共通点を解説します。不安を解消して納得した状態で手術を受けることができます。
冒頭文のNG表現（使用禁止） 「この記事では〜」「今回は〜」「こちらでは〜」「ここでは〜」「内容を理解することで〜」「〇〇に悩んでいませんか？」

未来の描き方（目指すレベル）

レベル例
❌ 知識止まり「情報がわかります」
△ 判断止まり「自分に合う選択ができるようになります」
◎ 行動後の状態「朝の体の重だるさが軽減しやすくなります」「翌日のパフォーマンスを保ちやすくなります」

4PREP法・SoWhat

本文は必ずPREP構造で書き、最後にSoWhatで締めます。

Point（主張）
結論・主張を1文で述べる
Reason（理由）
なぜそう言えるかを説明する
Example（具体例）
根拠・数値・事実で裏付ける
SoWhat（行動）
読者が次に取る行動を示す

SoWhatのルール

説明で終わらず、読者が次に取る行動を示してください。各H3に必ず入れます。H2ブロックの最後のH3末尾には、H2全体のSoWhatも含めます。

NG（説明止まり）埋没法は元に戻る可能性があります。
OK（行動まで）埋没法は元に戻る可能性があるため、医師の診察を受けて自分に合った施術を選ぶことが大切です。

チェックポイント

  • 最初のPoint（主張）の繰り返しではなく、一段階具体化された内容になっているか
  • 「次は自分は何をしたらよいか」が具体的にイメージできるか

5リンク・画像の基礎知識

内部リンクの考え方

内部リンクとは、同サイト内の別記事へのリンクです。ユーザーの回遊を促し、サイト全体のSEO評価にも貢献します。設置先は自分で判断してください。

項目ルール
リンク先の選び方本文中で触れたテーマに関連する同サイト内記事を選ぶ。カニバリしない記事（KWが被らない）を選ぶ
設置場所本文中の自然な文脈に設置する。「詳しくはこちら」だけのリンクはNG
アンカーテキストリンク先記事のメインKWを含む言葉にする。「こちら」「詳細」「詳しくはこちら」はNG
設置数1記事あたり2〜4箇所程度。過剰なリンクはNG
NGAGAの費用については詳しくはこちらをご覧ください。（抽象的すぎる）
NGクリニック別の費用相場は「AGA治療 費用 クリニック比較」で解説しています。（KWそのままはスパム判定リスクあり）
OKクリニック別の費用については各院のAGA費用比較でまとめています。（内容を端的に表す自然な言葉）

関連記事の考え方

記事末尾（まとめH2の後）に設置します。設置先は自分で判断してください。選ぶ基準は以下の通りです。

選ぶ基準内容
テーマの補完関係この記事を読んだ後に次に知りたくなるテーマの記事を選ぶ
同ジャンル・近いKW同サイト内の同ジャンル記事から選ぶ。カニバリしない（KWが被らない）記事を選ぶ

参考文献・外部リンクの必要性

統計データ・医学的な数値・臨床結果を記載する場合は、必ず一次情報源のURLをセットで記載してください。外部リンクは記事の信頼性を高め、医療広告ガイドラインへの対応にもなります。

使える参照元使えない参照元
クリニック公式サイト・厚生労働省HP・専門学会の発表資料個人ブログ・Yahoo!知恵袋・他社まとめサイト・日付不明の記事

altテキストの考え方

altは画像の内容を検索エンジンとスクリーンリーダーに伝えるテキストです。画像が表示できない場合の代替テキストにもなります。

ルール例
画像の内容を具体的に説明するalt="AGA治療の料金をクリニック別に比較した表"
記事のKWを自然に含める（詰め込みNG）alt="医療脱毛クリニックの施術室の様子"
装飾画像・区切り画像は空にするalt=""
「〜の画像」「〜の写真」は不要✕ alt="AGAの画像"　→　✓ alt="AGA（男性型脱毛症）の進行段階図"

6リンクのHTML記述ルール

アフィリエイトリンク（案件リンク）

案件へのリンクは記事内にASPリンクを直接設置しません。必ずメタリフ（meta refresh）ページを経由して設置します。

属性記述値理由
relnoopener noreferrer nofollowセキュリティ対策・リファラ送信防止・リンク評価を渡さない
target_blank別タブで開く
<a href="/metaref/[メタリフ名]/" rel="noopener noreferrer nofollow" target="_blank">クリニック名</a>

メタリフ（meta refresh）について

メタリフとは、ASPリンクへのリダイレクト専用ページです。記事内には「自サイトのメタリフページURL」へのリンクを設置し、そこからASPへ転送します。

項目内容
設置対象の院上位3位のクリニック（CTAボタンを設置する院）のみ。4位以下は設置しない
ファイル名・設置場所サイトごとに担当者（三浦）から指定される。勝手に決めない

メタリフページのHTMLは以下のコードを使用します。

<!DOCTYPE html>
<html lang="ja"><head>
<meta charset="UTF-8">
<meta http-equiv="refresh" content="0;url=[ASPのリンクURL]">
</head>
<body></body>
</html>

外部リンク（参考文献・官公庁・クリニック公式等）

信頼できるサイトへのリンクはnofollowを付けません。

属性記述値
relnoopener noreferrer（nofollowは不要）
target_blank
<a href="https://example.com" rel="noopener noreferrer" target="_blank">参照テキスト</a>

パラメータのルール

アフィリリンク（メタリフURL）には計測用パラメータを付与します。どのページのどの位置のどの種類のリンクから発生したか追跡できます。

形式：?記事スラッグ_コンテンツ位置_リンクタイプ

要素値説明
記事スラッグdiet-rybelsus などリンクを設置した記事のスラッグ
コンテンツ位置osusumeおすすめ商品紹介見出し内
osusume2再訴求BOX内
hikaku比較表・比較セクション内
matome記事末尾（まとめ）
リンクタイプbtボタン
bn画像リンク
txtテキストリンク
<!-- おすすめ紹介見出し内のボタン -->
<a href="/metaref/rybelsus/?diet-rybelsus_osusume_bt" rel="noopener noreferrer nofollow" target="_blank">公式サイトはこちら</a>

<!-- 再訴求BOX内のボタン -->
<a href="/metaref/rybelsus/?diet-rybelsus_osusume2_bt" rel="noopener noreferrer nofollow" target="_blank">公式サイトはこちら</a>

<!-- まとめ部分のテキストリンク -->
<a href="/metaref/rybelsus/?diet-rybelsus_matome_txt" rel="noopener noreferrer nofollow" target="_blank">リベルサスの公式サイト</a>
パラメータの仕組み?以降はURLとしては無視されるため、ユーザーは同じページに飛ぶ。ただしアクセス解析ツールには別URLとして記録されるため、リンクごとの発生を計測できる。

指示語・参照語（こそあど）

このそのここそこ これ次以上以下

記事参照表現

この記事本記事このブロック 先ほどこの後上記下記 ページ上部記事冒頭前述の 次のセクション〜で紹介します〜をご覧ください

橋渡し文・不要な接続詞

つまりそれでは 以下で詳しく解説します次の項目をご確認ください

推量・疑問形（タイトル・見出し・本文すべて禁止）

〜でしょう〜かもしれません〜ではないでしょうか

→ 言い切り（「〜です」「〜してください」）に変換してください。

見出し内の記号

見出し使用可使用禁止
H1（タイトル）「！」「補足の（）」のみ？・・・｜：などの区切り記号すべて
H2・H3「！」「？」「補足の（）」・・・｜：などの区切り記号

その他の禁止事項

項目ルール
「」（隅付き括弧）の強調使用強調は太字・マーカーで行うため、文中の「」は禁止
自分語り・共感の強要「〜ですよね」「〜と思いませんか」など読者への同意強要は禁止
削除対象の文他の記事・他のジャンルでも通じる一般論の一文、主語がない文、主張のない短い一文

8医療広告 禁止表現と必須記載

禁止表現と言い換え

種類❌ NG表現✅ OK表現
断定・最上級絶対・100%・最強・日本一・最安値〜の可能性があります・〇〇円〜
比較優良他社よりも優れています・A社より安い〇〇円（税込）・自社内比較で〜
権威の誤用厚生労働省が推奨する施術です厚生労働省に承認された機器を使用しています
体験談私はこのサプリで5キロ痩せました成分の特徴・効果の保証ではない旨を明記
Before/After写真だけで「激変！」と煽る写真横に「リスク・副作用・費用」を必ず併記

自由診療の必須記載事項（1カ所にまとめて記載）

自由診療（保険適用外）を扱う記事では、以下の項目を必ず1つのブロックにまとめて記載してください。

  • 「本施術は公的医療保険が適用されない自由診療です」の明記
  • 標準費用（税込）の記載
  • 回数・期間の記載
  • リスク・副作用の記載
  • 承認医薬品の有無の記載
  • 別途費用の記載（発生する場合）

数値の根拠について

金額の相場・統計データなど「数字」を出す際は、必ず一次情報（クリニック公式サイト・官公庁・専門学会）のURLをセットで記載してください。

OK（使える参照元）NG（使えない参照元）
クリニック公式サイト（LP）・厚生労働省HP・専門学会の発表資料個人ブログ・Yahoo!知恵袋・他社まとめサイト・日付不明の記事
迷ったらLPを参照案件のLPで使われている表現は法務チェック済みです。独自の表現を作らず、LPのトーンに合わせましょう。

9AI表現の直し方

AI生成文に多いパターンを3つ確認してください。不自然でなければ全部直す必要はありませんが、以下のパターンが多いと品質が下がります。

① 抽象語で逃げている

具体性を避けて「それっぽい抽象語」で締めているパターン。

傾向です判断につながります納得感のある選択 後悔しにくいです設計です方向性はさまざまです
NG後悔しにくい選択になります。
OK追加費用で困るリスクを減らせます。

② 誇張している

感情に振りすぎた表現・情報記事として信頼性が落ちる表現。

救世主味方成功の鍵 最適スムーズです最もふさわしい
NGこれが成功の鍵です。
OK〇〇を確認することが重要なポイントです。

③ 断定回避している（答えを出さずに逃げている）

PLUSは「読者に考えさせる記事」ではなく「読者を導く記事」にします。

満足度を左右します〇〇な印象です 〇〇といえそうです判断はあなた次第です
NG自分に合うかどうかを整理することが大切です。
OK価格重視ならAが向いています。着心地重視ならBのほうが合いやすいです。

10公開前チェックリスト ― コンテンツ確認

タイトル

  • メインKWが含まれている（前半に配置）
  • サブKWが含まれている
  • メインKWがサブKWより前半に配置されているか
  • 使用可能な記号は「！」「補足の（）」のみ（？・・・｜：等は不可）
  • 文字数30文字前後（KW構成により柔軟対応）
  • 音読して違和感がない（不自然な語順・KW詰め込みなし）

H2見出し

  • 1記事あたり3〜5個
  • ユーザーが知りたい順になっているか
  • メインKWが含まれているか
  • サブKW解説ブロックにサブKWが含まれているか
  • H2だけ読んで記事の流れが分かるか
  • そのKWでないと通じない表現になっているか（汎用的な見出しになっていないか）
  • 使用可能な記号は「！」「？」「補足の（）」のみ（・・・｜：等は不可）
  • まとめH2は「まとめ」という見出し名を使っていない（記事の結論を示す言葉にする）
  • まとめH2内に次の行動（予約・相談・問い合わせ）への誘導が含まれている
  • 1つのH2内に箇条書きまたはテーブルが最低1つ含まれている

H3見出し

  • 1つのH2につき3〜4個（概要H2などは例外あり）
  • 1つのH3で1つのトピックだけを扱っている（複数の話題を混ぜない）
  • H3の本文は3段落以上5段落以内（箇条書き・テーブルは1段落として数える）
  • H2テーマからズレていない（話が飛んでいない）
  • 使用可能な記号は「！」「？」「補足の（）」のみ（・・・｜：等は不可）
  • 似た内容のH3が重複していない（被りのない構成になっているか）
  • そのH2内で知りたい順になっているか

冒頭文（記事導入）

  • ベネフィット（読後どんな状態になれるか）が示されている
  • 「この記事では」「今回は」「こちらでは」を使っていない
  • 「〇〇に悩んでいませんか？」系の問いかけを使っていない
  • メインKW・サブKWが前半に入っている
  • 未来の描写が「知識」止まりでなく「行動後の状態」まで踏み込んでいる

H2下導入文

  • 各H2の直下に1〜2文入れている
  • 「このH2を読む価値・得られるもの」に触れている
  • 単なる内容の説明（箇条書きの予告）になっていない

本文・PREP

  • 各H3にPREP構造（主張→理由→具体例→SoWhat）がある
  • SoWhatが「説明」で終わらず、読者の次の行動を示している
  • 指示語（こそあど）・記事参照表現を使っていない
  • 推量・疑問形（〜でしょう・〜かもしれません）を使っていない
  • 削除対象の文（一般論・主語なし・主張なし）がない

テーブル・箇条書き

  • 表・箇条書きの前に見出し（タイトル）がある
  • 表・箇条書きの後に「その情報をどう受け取ってほしいか」のSoWhat（読者の判断・行動）が書いてある
  • 「以下のように」「次の通りです」などの不要な前置きを削除している
  • 比較には表を、並列情報の羅列には箇条書きを使い分けている

改行・強調（マーカー）

  • 1〜2文で改行している（4文以上の連続はNG）
  • 話題が切り替わる箇所で段落（<p>）を分けている
  • マーカーはH3ごとに1カ所のみ（一番重要な箇所だけ）
  • H2下導入文にも1カ所マーカーがある
  • デメリット・ネガティブな箇所にマーカーを引いていない
  • 一文まるごとのマーカーはNG（フレーズ単位にとどめる）
  • 単語だけ・複数箇所への過剰なマーカーになっていない

AI表現

  • 抽象語で逃げていない（具体的な状態に置き換えられているか）
  • 誇張表現がない（救世主・鍵・最適 等）
  • 断定回避せず、読者に合う方向を示している

ランキングブロック（比較・地域記事のみ）

  • 全院のクリニック紹介ブロックが同じHTML構成になっている
  • 「選び方」セクションで挙げた比較軸（実績・料金・アクセス等）が各院の紹介文でも網羅されている
  • 1〜3位のみCTAボタン付き・見出しリンクあり。4位以下はリンク・CTAなし

エラーチェック

  • Crescent Eve（HTML5選択 → ツール → 文法チェック）でチェック済み
  • HTML Tag エラーチェッカーでタグの閉じ忘れ・構造エラーをチェック済み
  • タグの閉じ忘れ・不要タグ・装飾崩れがない

医療広告

  • 禁止表現（絶対・100%・最強・他社比較等）を使っていない
  • 自由診療の場合、必須記載事項（費用・リスク・回数・承認情報等）を1カ所にまとめている
  • 数値に一次情報の参照元URLを付けている

11公開前チェックリスト ― 入稿・公開設定

WordPress 設定

  • 記事タイトルをWPのSEOタイトル欄に設定した
  • メタディスクリプション（80〜100文字）をWPに設定した
  • カテゴリ・タグを設定した（担当者指定の設定に合わせる）
  • アイキャッチ画像を設定した
  • 目次の表示対象はH2のみに設定した（H3を目次に含めない）

内部リンク・関連記事

  • 本文中に関連テーマの同サイト記事への内部リンクを2〜4箇所設置した
  • アンカーテキストはリンク先の内容を自然に表す言葉になっている（「こちら」「詳細」はNG。KWそのままもスパム判定リスクあるのでNG）
  • リンク先がカニバリしていない（この記事とKWが被っていない）
  • 関連記事をまとめH2の後に設置した（カニバリしない・テーマが補完関係にある記事）
  • 内部リンクのリンク先が正常に開くか確認した

リンクのHTML属性

  • アフィリリンク（案件リンク）: rel="noopener noreferrer nofollow" target="_blank" になっている
  • アフィリリンクのhrefはメタリフページのURLになっている（ASPリンク直貼りNG）
  • 外部リンク（参考文献等）: rel="noopener noreferrer" target="_blank" になっている

画像

  • 画像をWEBP形式に変換した（PNG/JPEGのままで入稿しない）
  • ファイル名が記事内容に関連した英数字になっている（例：icl-osaka-01.webp）
  • altテキストを設定した

公開後

  • 公開後にブラウザで表示崩れがないか確認した（PC・スマホ両方）
  • Google Search Consoleでフェッチ（URLインデックス登録リクエスト）を実施した
  • 担当者に完了報告をした
